# Number Guessing Game

A simple JavaScript game where you guess a number between 1 and 100. You have 10 attempts to find the correct number.

## How to Play
1. Enter a number between 1 and 100 when prompted.
2. The game will tell you if your guess is too high or too low.
3. Keep guessing until you find the number or run out of attempts.
4. If you guess correctly, you win! If not, the correct number is revealed.

## Features
- Random number generation.
- Input validation.
- Feedback on guesses.
- Limited attempts for added challenge.

## How to Run
Open the JavaScript file in a browser or use CodeSandbox.
